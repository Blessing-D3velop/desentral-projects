# Desentral Projects – Business Website

🌐 **Live Website:** https://desentral-projects.vercel.app/

**Designed & Developed by Blessing Muthivhi**

## About the Project

Desentral Projects is a website I developed to establish a professional online presence for the business.

The focus was on creating a modern and visually appealing website that communicates the business's identity while providing visitors with a smooth browsing experience.

I worked on the frontend structure, styling, JavaScript functionality and overall presentation, making sure the website is responsive and accessible across different screen sizes.

I also implemented SEO-related configurations to help search engines discover and understand the website.

## Features

- **Modern Website Design:** A clean and professional interface.
- **Responsive Layout:** Adaptable to desktop, tablet and mobile screens.
- **Interactive Elements:** JavaScript-powered functionality.
- **Custom Branding:** Website icons, favicon and social sharing image.
- **SEO Optimisation:** Search engine metadata and verification.
- **Search Engine Indexing:** Sitemap and robots.txt configuration.
- **Web App Manifest:** Browser and device branding configuration.
- **Social Media Sharing:** Open Graph image configuration.

## SEO Implementation

I included several technical SEO improvements to help establish the website's search engine presence.

These include:

- Google site verification meta tag.
- SEO-friendly page metadata.
- XML sitemap.
- Robots.txt configuration.
- Open Graph metadata.
- Social sharing image.
- Favicon and application icons.
- Web manifest configuration.

## Development Approach

My approach to this project was to keep the website lightweight, organised and easy to maintain.

I used vanilla JavaScript instead of relying on large frontend frameworks, alongside custom CSS for the layout and visual presentation.

I also made sure the website had the basic technical SEO foundations needed for search engine discovery.
